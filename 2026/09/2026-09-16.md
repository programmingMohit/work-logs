### Investigation & Research

#### Kubernetes Deployments at scale (Discord cost-attribution blog)
- **Repo:** none (general research)
- **Question:** Discord's post says its shared API code is "continuously deployed to several hundred separate Kubernetes deployments". What is Kubernetes, and how does it relate to Deployments?
- **Outcome:**
  - Kubernetes places containers onto machines and gives them IPs, storage and DNS.
  - A Deployment is a Kubernetes object that owns a ReplicaSet, which in turn runs N pods.
  - "Several hundred deployments" means several hundred separate Deployment objects. Each one is a workload that is scaled and rolled out on its own, all running the same shared code.
- **Time:** 11:48–12:57
