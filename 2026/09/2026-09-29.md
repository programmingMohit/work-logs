#### Park expired sessions instead of writing off attachments
- **Repo:** `audit-lite` · branch: `fix/auth-park-attachment-upload`
- **What was done:** When the auth token has expired, an attachment upload is now parked instead of being marked failed for good. It recovers once the user logs in again. The chosen approach adds a new outcome tag and accepts a short recovery delay (up to about 60s after re-auth) rather than widening `isBlocked`, which would have changed the notification copy too. The docs were updated before the code changes. A follow-up narrowed the park so it only applies to refusals that a new token actually fixes. Master, which now includes #2065, was merged back into the branch. Progress was posted on Fizzy card 1774.

- **Repo:** `audit-lite`
