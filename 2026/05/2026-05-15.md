`★ Insight ─────────────────────────────────────`
- The PostHog upgrade → Metro resolver fix sequence is a classic React Native gotcha: many modern npm packages publish ESM-style `exports` maps with subpath conditions that Metro's default resolver (with package exports disabled for compat) can't follow, so a version bump silently breaks bundling until you teach the resolver about the subpaths.
