#### Server-side "submit accepted" event to fix false stuck reports
- **Repo:** `api-reports` · branch: `feat/server-side-submit-delivered-event`
- **What was done:** This came out of the KFC report of 30+ stuck audits. Checking those reports in Mongo showed they had completed. The submit worked every time. What failed was the phone's `report_submission_delivered` event, which never reached PostHog, and the dashboard counts any report without that event as stuck. The fix: `submitV2` now sends `report_submission_server_accepted`, keyed by `firebaseReportID`, through a new `posthogCapture` helper with tests. The stuck insight on dashboard 28 now counts a report as stuck only if neither event exists. `POSTHOG_API_KEY` was also set up in the production env, and the PR was merged.
