### Tasks & Changes

#### Unstick comment sheets on failed submit
- **Repo:** `audit-lite` · branch: `fix/issue-comment-sheet-stuck-submitting`
- **What was done:** All four comment sheets (`issue-comments.tsx`, `quick-resolve-comment.tsx`, `issue-resolved-comment.tsx`, `issue-block-comment.tsx`) called `mutateAsync` with no `try/catch`, so a rejection skipped both `setIsLoading(false)` and `resetData()` — the button stayed on "Submitting" and the sheet could not be closed. Root cause traced to `issue-repository.ts:340` throwing on any apisauce `res.problem`, including `TIMEOUT_ERROR`/`CONNECTION_ERROR`, which are client-side verdicts: the comment does land server-side while the client reports failure. Wrapped each handler in `try/catch/finally` so `isLoading` always releases, kept `resetData()` inside `try` to preserve draft text and attachments on failure, added per-sheet `error_type` for Sentry and an error toast (new `issueActivity.commentFailed` key across all 7 locales). Rolled back the optimistic `issueDetailsAtom` status flips in the resolved/blocked sheets, which previously left the screen claiming a `resolved`/`blocked` state that was never written. Suppressed duplicate toasts where a second mutation already reports its own error. Added two regression tests in `issue-comments.test.tsx`; suite green at 518 passed / 0 failed, translations validated at 1488 keys per locale.
- **Commits:**
  - `05df241` — fix: unstick comment sheets when a submit fails

#### Keep comment input clear of the resolve button
- **Repo:** `audit-lite` · branch: `fix/issue-comment-sheet-stuck-submitting`
- **What was done:** `issue-activity-tab.tsx` reserved a hardcoded `pb="$10"` (44px) for the absolutely positioned resolve bar, which is actually ~66dp tall, clipping the "Add a comment…" box. Switched to the bar's measured height via `onLayout` so the reserve adapts to font scale and longer localised button text, and collapses to `0` when the button is hidden (no edit-status permission, or blocked issue). Verified on device (SM-M346B).
